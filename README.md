# React + Vite

A full-stack application that searches for news and allows users to register, log in, and save their news cards.

## Tech Stack

### Frontend

- **React.js** with functional components and hooks
- **React Router v6** for client-side routing
- **Context API** for global state management (`CurrentUserContext`)
- **CSS BEM** for structured styling
- **REST API integration** with JWT authentication
- **Vite** for fast builds and hot reload

### Backend

- **Node.js** + **Express.js** REST API
- **MongoDB** + **Mongoose** for database modeling
- **JWT authentication** (token-based)
- **bcrypt** for password hashing
